# 要件定義書

## 1. 業務要件

### システム概要

Spotifyのライブラリに直近で保存した楽曲をスッキリと一覧表示し、自分の「今の音楽の入り口」を確認するためのWebアプリケーション。FastHTMLとhtmxを活用し、リロード不要で高速かつ直感的にライブラリの最新状況をブラウジングできる。

### ユースケース

* Spotifyアカウントで認証を行い、ライブラリ接続を確立する。
* 「最新の追加曲を取得」ボタンを押し、ライブラリ追加日時（`added_at`）に基づいた最新10曲をリストアップする。
* 楽曲のアルバムアート、タイトル、アーティスト名、追加日をクリーンなダークテーマUIで確認する。

---

## 2. 機能要件

### 機能一覧

* **Spotifyデータ取得:** `Spotipy` を介し、`current_user_saved_tracks` からライブラリ追加日時（`added_at`）を含むメタデータを取得。
* **GUI可視化:** htmxによる `hx_post` 通信で、テーブル領域のみを非同期更新。アルバムアートは `Img` コンポーネントで動的に生成。
* **ロギング:** `logging.config.dictConfig` を用いた階層的なロギング管理（`disable_existing_loggers=False` によるシステムロガーの保護）。

---

## 3. 非機能要件

* **開発環境:** Python 3.13, FastHTML, uv
* **品質保証:** `mypy` による厳格な型チェックと `pytest` によるテスト。`Ruff` によるコード品質の維持。
* **セキュリティ:** 環境変数によるAPI認証情報の秘匿。
