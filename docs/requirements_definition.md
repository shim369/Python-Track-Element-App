# 要件定義書

## 1. 業務要件

### システム概要
Spotifyのライブラリに保存した楽曲を「直近の追加曲」と「週間トップ楽曲」の2つのタブで整理し、効率的にブラウジングするWebアプリケーション。FastHTMLとhtmxを活用し、リロード不要で高速に表示を切り替える。また、週間トップ楽曲のみを対象としたプレイリスト生成機能を備える。

### ユースケース
* Spotifyアカウントで認証を行い、ライブラリ接続を確立する。
* **タブ切り替え:** 「直近の追加曲」「週間トップ楽曲」の各タブで、それぞれの条件に基づいた10曲をリストアップして確認する。
* **プレイリスト生成:** 「週間トップ楽曲」タブにおいて、表示されている10曲を元に新しいプレイリストを作成し、Spotify上に同期する。

---

## 2. 機能要件

### 機能一覧
* **Spotifyデータ取得:** `Spotipy` を介し、ライブラリ追加日時および再生数/人気度に基づいたメタデータを取得。
* **GUI可視化:** htmxによる `hx_post` 通信で、タブ内のテーブル領域のみを非同期更新。
* **プレイリスト自動生成:** 「週間トップ楽曲」タブのみで実行可能なプレイリスト作成機能。
* **ロギング:** `logging.config.dictConfig` による階層的なロギング管理（`disable_existing_loggers=False`）。

### 非機能要件
* **開発環境:** Python 3.13, FastHTML, uv
* **品質保証:** `mypy` による厳格な型チェック、`pytest` によるテスト、`Ruff` によるコード品質維持。
* **セキュリティ:** 環境変数によるAPI認証情報の秘匿。
