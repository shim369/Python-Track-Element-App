
# 画面遷移・処理フロー図

メイン画面（Streamlit）を中心に、認証、データ分析、選曲ロジック適用、グラフ可視化、およびSpotify書き出しの処理フローです。

```mermaid
%%{init: {'flowchart': {'curve': 'linear'}}}%%
flowchart TD
    A[メイン画面: Streamlit UI]

    A --> B[「Spotifyでログイン」ボタン押下]
    B --> C[SpotifyClient経由でOAuth認可実行]
    C --> D[アクセストークンをセッションに保持]
    D --> E[画面に入力・操作UIを有効化表示]
    E --> A

    A --> F[「マイ音楽成分を分析」ボタン押下]
    F --> G[SpotifyClientで直近50曲のデータを一括取得]
    G --> H[TrackDataデータクラス群へ変換]
    H --> I[Plotlyで成分レーダーチャートを描画]
    I --> A

    A --> J[選曲ロジックの選択 & 分析開始]
    J --> K[TrackAnalyzerでPandas DataFrameを構築]
    K --> L{"選択されたロジックは？"}
    L -- フェードイン選曲 --> M[Energyの数値を右肩上がりにソート]
    L -- タイムトラベル選曲 --> N[関連アーティストを取得し70〜80年代曲を抽出]
    M --> O[選曲結果リストを返却]
    N --> O
    O --> P[画面上に楽曲リスト（テーブル）と遷移グラフを描画]
    P --> A

    A --> Q[「Spotifyに保存」ボタン押下]
    Q --> R[SpotifyClient経由で新規プレイリストを自動作成]
    R --> S[選曲されたトラックID群をプレイリストに追加保存]
    S --> T[画面に「保存完了トースト」を表示]
    T --> A

    A --> U[エラー発生: トークン切れ・データ不足等]
    U --> V[遅延フォーマット評価によるロギング実行]
    V --> W[画面にエラー通知アラートを表示]
    W --> A

```
